    ABOUT THE PROJECT

    Eye health, made easier to explore.

    ICheck is a student project exploring how machine learning can support eye-health awareness through accessible, image-based screening.

    !

    Important disclaimer

    ICheck is an educational student prototype, not a clinically validated diagnostic tool. Its results are not medical advice. If you have any concerns about your eyes, please consult a qualified eye-care professional.
